# Interplanetary Mission Planner

This project is a Pythonbased orbital mechanics simulator developed as part of my aerospace engineering portfolio.

The objective is to build a simplified interplanetary mission planning environment from first principles, beginning with planetary motion and progressing toward transfer orbit analysis and mission trajectory visualization.

Current Features

* Heliocentric coordinate system
* Earth circular orbit simulation
* Mars circular orbit simulation
* Independent planetary motion using angular velocity
* Real-time animation using Matplotlib
* Orbital visualization in Astronomical Units (AU)

tools used

* Python
* NumPy
* Matplotlib

Development Roadmap

V1

* Static Earth orbit
* Static Mars orbit
V2
* Animated Earth motion
* Animated Mars motion
* Independent orbital propagation
